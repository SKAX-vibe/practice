# reply-rules — 회신 메시지 문구 규칙

이 Skill은 회신 초안 `## 1. 회신 메시지 (초안)`의 **문장 표현만** 정한다.

| 담당 | 내용 |
|---|---|
| 이 Skill | 1장 메시지의 인사 · 안내 · 금지 표현 |
| `CLAUDE.md` | 단가 적용 · 확인 필요 사유 · 금액 계산 · 초안 2 · 3장 형식 · 표기 |
| `quote-reply` Skill | 미회신 찾기 · 보고서 갱신 · 검증 등 실행 순서 |
| `tools/price_lookup.py` | 단가 · 확인 필요 사유 판정 |

단가 · 금액 · 확인 필요 판정은 여기서 바꾸지 않는다. 판정 결과를 문장으로 옮길 때의 표현만 따른다.

## 규칙

1. **첫 문장은 문의에 대한 감사 인사다.**
   - 예: `견적 문의 주셔서 감사합니다.`
   - 인사말(`안녕하세요.` 등)은 감사 인사 뒤에 둔다.
2. **금액이 부가세 별도임을 품목 표 바로 아래에 쓴다.**
   - 표 다음 줄: `- 금액은 부가세 별도입니다.`
3. **확인 필요 품목은 `담당자가 확인 후 안내`로 표현한다.**
   - 예: `- 방진 패드(40개)는 담당자가 확인 후 안내드리겠습니다.`
   - 사유(단가표에 없음, 단위 불분명)는 메시지에 쓰지 않는다. 사유는 초안 2 · 3장에 둔다.
   - 확인 필요 품목은 메시지의 품목 표에 넣지 않는다.
4. **납기를 확약하지 않는다.**
   - 금지 예: `○일까지 납품 가능합니다`, `바로 출고됩니다`, `재고가 있습니다`
   - 납기 문의가 있으면: `- 납기는 담당자가 확인 후 안내드리겠습니다.`
5. **할인을 약속하지 않는다.**
   - 금지 예: `10% 할인해 드리겠습니다`, `할인 적용 금액`, `특별가`
   - 할인 요청이 있으면: `- 요청하신 할인은 담당자가 확인 후 안내드리겠습니다.`
   - 할인 요청을 3장에 `확인 필요`로 남기는 규칙(`CLAUDE.md` · `verify.py`)은 그대로 지킨다.

## 메시지 틀

```markdown
> **수신:** <보낸 사람> 님
> **제목:** [견적 회신] <첫 품목> 외 N건
>
> 견적 문의 주셔서 감사합니다. 요청하신 품목의 견적을 아래와 같이 안내드립니다.
>
> | 품목 | 수량 | 단가 | 금액 |
> |---|---:|---:|---:|
> | ... (단가가 확정된 품목만) | | | |
> | 합계 | | | N원 |
>
> - 금액은 부가세 별도입니다.
> - <확인 필요 품목>(<수량>)은 담당자가 확인 후 안내드리겠습니다.
> - (납기 · 할인 요청이 있으면) 담당자가 확인 후 안내드리겠습니다.
>
> 감사합니다.
```

## 작성 후 점검
- 첫 문장이 감사 인사인가
- 표 바로 아래에 부가세 별도 문장이 있는가
- 확인 필요 품목마다 `담당자가 확인 후 안내`가 있는가
- 납기 · 재고 · 할인을 약속하거나 단정하는 표현이 없는가
