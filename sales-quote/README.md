# 트랙 A · 영업 — 견적 회신

기준일은 2026-06-15(월)이다. 모든 자료는 실습용 가상 데이터이다.

**실습 목표:** 견적 문의를 단가표와 대조해 회신 초안을 만들고(Day 1), 미회신 문의를 찾아 초안까지 작성하는 에이전트로 확장한다(Day 2).

- 입력: `inbox/` — 견적 문의 3건, `data/단가표.csv` — 품목별 단가 (수정 금지)
- 분석: 품목별 단가 적용, 단가표에 없는 품목·단위 불분명 수량 식별
- 결과: `outbox/drafts/회신_거래처.md` (문의별), `report/견적처리.md` (처리 현황)

### Pass 기준
1. 초안의 단가 = 단가표의 단가
2. 단가표에 없는 품목과 단위가 불분명한 수량은 '확인 필요'

### 도구
| 구분 | 이름 | 하는 일 | 보고 항목 |
|---|---|---|---|
| Day 1 커맨드 | `/quote [견적문의_NN \| all]` | 문의 읽기 → 단가 찾기 → 초안 작성 → 저장 | 처리 건수 · '확인 필요' 품목 |
| Day 2 Skill | `quote-reply` | 미회신 문의를 찾아 초안 작성 → 처리 현황 갱신 → 검증 → `report/검증결과.md` | 최종 PASS/FAIL |

업무 규칙은 `CLAUDE.md`에 있다.

### 검증
원본·초안·보고서는 읽기만 한다.

```
python scripts/verify.py
```

문의마다 초안 존재, 품목 목록, 수량·단가·금액, 합계(할인 미적용), 할인 요청 표기를 확인하고, `report/견적처리.md`의 문의별 집계와 확인 필요 품목을 확인한다.
전체 통과 시 `결과: PASS`(종료 코드 0), 하나라도 불일치하거나 초안이 없는 문의가 있으면 `결과: FAIL`(종료 코드 1).
