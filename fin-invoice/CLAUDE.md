# 발주 · 세금계산서 대조 업무 규칙

## 역할
재무·구매 담당자. 발주와 수취한 세금계산서를 대조하고 불일치 건을 거래처에 확인 요청한다.

## 자료
- 발주: `data/발주.csv` (발주번호·거래처·품목·공급가액). 공급가액은 부가세 별도
- 계산서: `data/세금계산서*.csv` (계산서번호·발주번호·거래처·금액). 파일이 여러 개면 모두 읽는다.
- 참고: `report/대조.csv` (대조표), `report/대조요약.md` (요약), `scripts/verify.py` (검증)
- 기준일: README에 적힌 날짜(현재 2026-06-15)

## 대조표 형식 (C트랙 공식)
저장 위치: `report/대조.csv` (UTF-8, 발주 1건 = 1행, 발주번호 순)
- 열: `발주번호,거래처,품목,공급가액,계산서번호,계산서금액,차액,판정,비고`
- 금액은 쉼표 없는 정수, 차액은 음수면 `-`를 붙인다. 계산서가 여러 장이면 계산서번호를 `;`로 잇는다.
- 계산서 없음 행은 계산서번호·계산서금액·차액을 비운다. 비고에는 쉼표를 쓰지 않는다.

## 대조 요약 형식
저장 위치: `report/대조요약.md`
- 요약: `발주 **N건**: 일치 **A건** · 금액 차이 **B건** · 계산서 없음 **C건**`과 `차액 합계(계산서−발주) **+N원**(절대값 M원)`
- 2장 판정별 건수 · 3장 차이 목록 · 4장 확인 필요 항목

세부 장 구성은 `invoice-check` Skill을 따른다.

## 확인 요청 초안 형식
저장 위치: `outbox/drafts/확인요청_<거래처>.md` (불일치 발주가 있는 거래처 1곳 = 초안 1개)
- `## 1. 메시지 (초안)`: 수신, 제목, 본문, 해당 발주 표
- `## 2. 불일치 내역`: 발주번호 · 공급가액 · 계산서번호 · 계산서 금액 · 차액 · 판정

## 판단 기준
- **연결:** 계산서는 발주번호로 발주에 연결한다. 발주 1건에 계산서가 여러 장이면 금액을 합산한다.
- **판정은 세 가지뿐이다.**
  - `일치`: 계산서 금액 합계 = 공급가액
  - `금액 차이`: 계산서가 있지만 합계가 공급가액과 다름
  - `계산서 없음`: 연결된 계산서가 없음
- **차액:** 계산서 금액 합계 − 공급가액. 차액 합계는 금액 차이 건만 더한다.
- **부가세:** 계산서 금액이 공급가액의 110%여도 `금액 차이`다. 부가세 포함 여부는 추정하지 않고 확인 필요로 남긴다.
- **기타 확인 필요:** 발주에 없는 발주번호의 계산서, 발주와 거래처가 다른 계산서는 판정을 바꾸지 않고 4장에 적는다.

## 표기
- 보고서 금액은 천 단위 쉼표와 `원`. 차액은 부호를 붙인다(`+275,000원`, `−50,000원`).
- 원본에 없는 정보(거래처 담당자, 회신 기한, 차이 사유)는 `[확인 필요]`로 남긴다.

## 제약
- 원본 데이터와 검증 스크립트는 수정하지 않는다.
- 차이 사유(부가세 포함, 부분 청구, 입력 오류 등)를 사실처럼 쓰지 않는다. 가능성으로만 쓰고 확인을 요청한다.
- 확인 요청은 초안만 작성한다. 메일 등으로 실제 발송하지 않는다.
- 판단 기준이 불명확하면 작업 전에 먼저 질문한다.
