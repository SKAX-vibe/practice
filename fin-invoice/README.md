# 트랙 C · 재무 · 구매 — 발주 · 세금계산서 대조

기준일은 2026-06-15(월)이다. 모든 자료는 실습용 가상 데이터이다.

**실습 목표:** 발주와 세금계산서를 대조해 대조표를 만들고(Day 1), 불일치 건의 거래처별 확인 요청 초안까지 작성하는 에이전트로 확장한다(Day 2).

- 입력: `data/발주.csv` — 발주 10건 (공급가액, 부가세 별도), `data/세금계산서.csv` — 세금계산서
- 분석: 발주별 판정(일치 · 금액 차이 · 계산서 없음)과 차액
- 결과: `report/대조.csv` (대조표), `report/대조요약.md` (판정별 건수 · 차이 목록), `outbox/drafts/확인요청_<거래처>.md`

### Pass 기준
1. 대조표 행 수 = 발주 건수
2. 판정 값은 일치 · 금액 차이 · 계산서 없음 세 가지뿐

### 도구
| 구분 | 이름 | 하는 일 | 보고 항목 |
|---|---|---|---|
| Day 1 커맨드 | `/match [발주번호 \| all]` | 발주와 세금계산서 대조 → 대조표 → 차이 목록 | 판정별 건수 · 차액 합계 |
| Day 2 Skill | `invoice-check` | 대조 → 불일치 건 확인 요청 초안 → 검증 → `report/검증결과.md` | 최종 PASS/FAIL |

업무 규칙은 `CLAUDE.md`에 있다.

### 검증
원본·대조표·보고서·초안은 읽기만 한다.

```
python scripts/verify.py
```

대조표의 행 수·판정 값·발주별 계산서번호/금액/차액/판정, 요약의 판정별 건수·차액 합계·차이 목록, 확인 요청 초안의 대상 거래처와 내역을 확인한다.
전체 통과 시 `결과: PASS`(종료 코드 0), 하나라도 불일치하면 `결과: FAIL`(종료 코드 1).
