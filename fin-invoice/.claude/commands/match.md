# 발주 · 세금계산서 대조 (Day 1 업무 도구)

대상: `$ARGUMENTS`

업무 규칙(계산서 합산, 판정 세 가지, 차액, 부가세, 표기, 제약)은 `CLAUDE.md`를 따른다.
불일치 건 확인 요청 초안과 검증 결과 저장까지 이어서 하려면 `invoice-check` Skill을 쓴다.

## 대상
| 인자 | 처리 대상 |
|---|---|
| `PO-2026-NNN` | 해당 발주만 화면에 보고. 대조표와 요약은 전체로 갱신 |
| `all` 또는 빈 값 | 전체 발주 |

`data/발주.csv`에 없는 발주번호면 처리하지 말고 그렇게 알려 준다.

## 절차
1. **발주와 세금계산서 대조:** `CLAUDE.md`, `data/발주.csv`, `data/세금계산서*.csv`를 읽는다. 발주번호로 연결하고, 여러 장이면 합산한다.
2. **대조표:** `report/대조.csv`를 쓴다. 행 수 = 발주 건수, 판정은 세 가지만 쓴다.
3. **차이 목록:** `report/대조요약.md`의 요약 · 2장(판정별 건수) · 3장(차이 목록) · 4장(확인 필요)을 쓴다. 기존 파일이 있으면 그 구조를 따라 갱신한다.
4. **검증:** `python scripts/verify.py`를 실행한다. 대조표·요약 항목이 FAIL이면 고친 뒤 다시 실행한다.
   - 확인 요청 초안 항목의 FAIL은 이 커맨드 범위 밖이다. 그대로 보고하고 `invoice-check`를 안내한다.

## 출력
```
판정별 건수: 일치 N건 · 금액 차이 N건 · 계산서 없음 N건 (합계 = 발주 건수)
차액 합계(계산서−발주): +N원 (절대값 M원)
| 발주번호 | 거래처 | 공급가액 | 계산서 금액 | 차액 | 판정 |   ← 일치가 아닌 건만
검증: 대조표·요약 PASS | FAIL (FAIL 항목과 기대값)
```
