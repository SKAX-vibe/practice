# 트랙 B · 인사 — 교육 이수 현황

기준일은 2026-06-15(월)이다. 모든 자료는 실습용 가상 데이터이다.

**실습 목표:** 직원명단과 수료기록을 대조해 과정별 이수 현황 리포트를 만들고(Day 1), 기한이 지난 미이수자에게 보낼 독려 초안까지 작성하는 에이전트로 확장한다(Day 2).

- 입력: `data/직원명단.csv` — 직원 12명 (가명), `data/교육과정.csv` — 과정 2개와 기한, `data/수료기록.csv` — 수료 기록
- 분석: 과정별 이수·미이수·지연 인원, 기한 후 수료, 명단 외 사번
- 결과: `report/교육이수.md`, `outbox/drafts/독려_<사번>.md` (지연 인원별)

### Pass 기준
1. 과정마다 이수 + 미이수 = 명단 인원
2. '지연'은 기한이 지난 사람뿐이고, 명단에 없는 사번은 '확인 필요'

### 도구
| 구분 | 이름 | 하는 일 | 보고 항목 |
|---|---|---|---|
| Day 1 커맨드 | `/training [과정명 \| all]` | 명단과 수료 기록 대조 → 이수율 표 → 미이수자 목록 | 미이수 인원 · 지연 인원 |
| Day 2 Skill | `training-nudge` | 이수 현황 → 지연 인원 독려 초안 → 검증 → `report/검증결과.md` | 최종 PASS/FAIL |

업무 규칙은 `CLAUDE.md`에 있다.

### 검증
원본·보고서·초안은 읽기만 한다.

```
python scripts/verify.py
```

과정별 대상·이수·미이수·이수율·지연·기한 후 수료, 미이수자 목록, 명단 외 사번, 요약 문구를 확인하고, 독려 초안이 지연 인원에게만 있는지 확인한다.
전체 통과 시 `결과: PASS`(종료 코드 0), 하나라도 불일치하면 `결과: FAIL`(종료 코드 1).
