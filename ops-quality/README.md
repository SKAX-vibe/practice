# 트랙 D · 품질 · IT 운영 — 불량 보고 주간 요약

기준일은 2026-06-15(월)이다. 모든 자료는 실습용 가상 데이터이다.

**실습 목표:** 주간 불량 보고서를 취합하여 불량 현황과 조치 상태를 분석하고 요약 보고서를 생성한다.

- 입력: `data/불량보고/` — 주간 보고 6건 (06-08 ~ 06-12)
- 분석: 라인별·유형별 불량 수량, 원인 및 조치 현황
- 결과: `report/품질주간.md`

### Pass 기준
1. 유형별 보고 건수 합 = 전체 보고 6건
2. 불량 수량은 보고 건수와 구분하여 집계
3. 원인이 없는 건은 `원인 미기재`
4. 미완료 조치 항목 별도 정리

### 보고서 생성 및 검증
1. `data/불량보고/`의 보고 전체를 집계해 `report/품질주간.md`를 작성(갱신)한다.
   - 표 구성: 2장 유형별 · 3장 라인별 · 4장 원인별(건수/수량) · 5장 미완료 조치
   - 빈 원인은 `원인 미기재`, 빈 조치는 `조치 미기재`로 표기
2. 원본과 대조해 검증한다(원본·보고서는 읽기만 함).

   ```
   python scripts/verify.py
   ```

   항목별로 `[PASS]`/`[FAIL]`을 출력하고, 불일치 시 보고서 값과 기대값을 함께 표시한다.
   전체 통과 시 `결과: PASS`(종료 코드 0), 하나라도 불일치하면 `결과: FAIL`(종료 코드 1).
